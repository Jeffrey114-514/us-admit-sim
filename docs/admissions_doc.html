一、录取概率公式（全局权重）

每所校先取基础录取率 baseRate（国际生用 acceptRateIntl，缺失则按国内率×0.6 保守估计），转成 logit：
logit = ln( baseRate / (1 - baseRate) ) S = 0.30·zGPA + 0.30·zSAT + 0.25·z活动 + 0.15·z文书/推荐 + (运气-5)·0.03 + (声望/100-0.4)·0.12 + (专业对口-0.5)·mw P = sigmoid( logit + 3.0·S ) 各项说明：
  • zGPA = (你的GPA + 课程强度加成 − 该校平均GPA) / 0.35。现在 全部 57 所都已填平均GPA（标"估算"者为按档位估计的近似值），低 GPA 会被真实惩罚。
  • zSAT = (你的SAT − 该校SAT中段) / 130，仅当该校有 SAT 数据且你考了 SAT 时计入（test-optional / 英港校 SAT 字段为空 → 不计入，符合现实）。
  • z活动 = (活动分/6 − 0.5)，活动分 = 活动数×0.5 + 领导角色×0.7 + 创办×1 + 国家级奖项×1.1 + 创造力×0.15。
  • z文书/推荐 = (文书+推荐)/20 − 0.5。
  • 专业对口 mw：综合评审校 0.18，按专业/英港校 0.5。

二、乘法惩罚与硬门槛（本次修复 B/C/D）

  • 国际生助学金：aidIntl="none" → ×0.62，"need-aware" → ×0.88，"need-blind" → 不扣。
  • 托福：没考 ×0.75；有校线但低于线 ×0.6；硬门槛：该校设了托福线却 toefl===0 → P 封顶 1.5%（国际生几乎都要英语证明）。
  • SAT：没考 ×0.7；硬门槛：该校 testReq=true 且 sat===0 → P 封顶 1.2%（仅对仍强制 SAT 的 7 所生效，test-optional 美校与英港校豁免）。
  • 顶尖校"信号弹"(spike/夏校)：原为单向 max(P, P2) 易掩盖短板；现改为加成减半 + 只取一半幅度（add×0.5，P += (P2−P)×0.5），对越挑的校加权越大，但不再无限抬升。
  • 国际生率兜底(D)：acceptRateIntl 缺失时不再退化到更宽松的国内率，改用 国内率×0.6（下限 0.8%）估计，已为 30 所美校补入该字段。

五、数据来源与待核对项

  • 原始真实字段：录取率、SAT区间、托福线、助学金政策、英/港校国际录取率，来自 US News 2026 / Common Data Set / 各校官方（部分标注估算）。
  • 本次补全(标"估算")：50 所美/英/港校的 gpaAvg（按录取率档位与学校声誉估计的"录取生平均GPA"近似值），以及 30 所美校的 acceptRateIntl（国内率×0.6）。这些值用于让模型"GPA/国际率真正参与计算"，欢迎你按权威数据源逐一校正。
  • 建模取舍：SAT 对 test-optional 与英/港校不计入（字段为空即豁免），符合现实；仅 7 所 test-required 美校启用 SAT 硬门槛。
